# 测试字体

`NotoSerifSC-subset.ttf`：Noto Serif SC（思源宋体）Regular 的子集，约 33 KB，只含少量测试用的汉字、常用中文标点和 ASCII 可打印字符。
来源：Google Fonts（`fonts.googleapis.com/css2?family=Noto+Serif+SC&text=...` 取到的 truetype 子集）。许可：SIL Open Font License 1.1，全文见 `OFL.txt`。

用于字体导入的 e2e（`app/e2e/fonts.spec.ts`、`app/e2e-electron/fonts.spec.ts`）。
