# 繁体简读 · 视觉与交互规格

> 界面风格参考 macOS 的「图书」。数值来源有三种：
> - 【官】来自公开的系统设计规范。
> - 【采】对参考界面的观察和测量。
> - 【定】本项目自行决定。
>
> 改这里的数值要先说明理由。

## 0. 全局

- 平台：Windows 11，WebView2，按 1 倍缩放下的 CSS px 设计。
- 窗口：无系统边框（`decorations: false`）+ Windows 11 系统阴影和圆角。右上角自己画 Windows 风格的窗口按钮。
- 中文界面。所有文案用简体，按钮用动词或名词，不加句号。

### 0.4 圆角、阴影、动效【定，参照 Tahoe 观感】

- 圆角：玻璃胶囊 = 高度的一半；弹出面板 16px；侧边栏面板 18px；主题方块 12px；按钮 10px；封面 3px。
- 玻璃阴影：`0 1px 2px rgba(0,0,0,.06), 0 8px 24px rgba(0,0,0,.10)`。
- 封面阴影：`0 1px 2px rgba(0,0,0,.10), 0 10px 20px -6px rgba(0,0,0,.28)`。封面左侧加书脊高光：在左边 0–8px 叠一层渐变，`rgba(255,255,255,.28) → rgba(0,0,0,.10) 3px → transparent 8px`。
- 动效：
  - 普通淡入淡出 180ms，曲线 `cubic-bezier(.2,.8,.2,1)`。
  - 弹出面板：缩放 .96→1，同时淡入，200ms。
  - 工具栏出现 180ms，隐藏 240ms。
  - 翻页：水平滑动 280ms（foliate 的 `animated` 属性）。
  - 系统设置了“减少动画”（prefers-reduced-motion）时，全部改为直接切换。

### 0.6 macOS 版的差异

本文其余部分按 Windows 写；macOS 版（Electron 官方 macOS 二进制 + 我们的 app.asar）只在下面几处不同，其他一律相同：

- **窗口**：隐藏标题栏，保留系统红黄绿（`titleBarStyle: 'hiddenInset'`），不画 2.3 的 Windows 窗口按钮。红黄绿约 52×12，位于窗口左上 (17, 20)。阅读窗口左工具栏让出 78px；工具栏自动隐藏时红黄绿一起隐藏。书库的侧边栏顶部 44px 本来就是留给它们的。
- **快捷键**：第 3 节的 Ctrl 全部换成 ⌘（Ctrl+Shift+D → ⇧⌘D）；字号增大显示为 ⌘+。另有中文菜单栏（繁体简读、文件、编辑、显示、窗口、帮助）。全屏用系统的（菜单“进入全屏”、绿色按钮），F11 不用。
- **字体**：界面字体 `-apple-system, "PingFang SC"`（0.1 表里的 Segoe/微软雅黑那几行只在 Windows 生效）；推荐字体换成：宋体-简（Songti SC，默认）、苹方（PingFang SC）、楷体-简（Kaiti SC）、圆体-简（Yuanti SC）、冬青黑体（Hiragino Sans GB），系统里没装的不显示。表在 `app/src/fonts/presets.ts`。
- **生命周期**：关掉所有窗口后程序不退出，点 Dock 图标重新打开书库；退出用 ⌘Q。
- **不做**：快捷方式、文件关联的自动注册（文件关联在 Info.plist 里），设置“关于”页里这一块不显示。

## 1. 书库窗口（参照 `mac-tahoe26-library-my-books-grid-light-en.png`、`mac-tahoe26-home-sidebar-light-en.png`）

- 窗口默认 1144×860，最小 760×520。
- **侧边栏**：浮在内容上方的玻璃面板。距窗口上、左、下各 10px，宽 240px【采：约占窗宽 20%】，圆角 18px。
  - 顶部留 44px 给拖动区。
  - 条目依次是：主页 /（分组）书库：全部。（不做联网书库，书库内也不做搜索）v1.1 再加“欲读清单”、“已读完”、“我的藏书”。
  - 条目高 34px【采】，左右内边距 10px，图标与文字间距 10px。
  - 选中项是深色实心胶囊（`--c-selected-pill`），圆角 10px。
  - 分组名 15/20 粗体，上方留 14px。
  - 底部固定一个“设置”条目（Windows 没有菜单栏，设置入口只能放这里）【定】。
- **内容区**：从侧边栏右边缘往右 45px 开始【采】，右侧留 45px。
  - 右上角是一个玻璃圆形“更多”按钮（36px），下拉菜单项：添加图书…（Ctrl+O）/ 分隔线 / 网格、列表 / 分隔线 / 排序方式：最近阅读、书名、作者、添加时间。
  - 大标题“全部”或“主页”，用 `--t-large-title`，距顶部 56px。
  - 封面网格：
    - 封面宽 185px【采】，宽高比 2:3【采 0.663】，列间距 26px【采】。
    - 封面一律底部对齐（不同比例的封面，下沿对齐，上沿参差）【采】。
    - 行距：从这行封面顶到下一行封面顶约 343px【采】，也就是封面下方的标签行加留白共 64px。
    - 列数随窗口宽度变化，封面宽度在 150–200px 之间浮动，填满整行。
  - 封面下方的标签行：高 20px，左边是状态，右边是“…”按钮。
    - 状态有三种：“新增”胶囊（导入后还没打开过）、进度“18%”、“已读完”。用 `--t-callout`，`--c-label-2`。
    - “…”菜单：打开 / 显示原文或显示简体 / 从书库移除…（需要确认）。
- **列表视图**：每行高 56px，依次是封面缩略图（高 44px）、书名（13/600）、作者、进度、添加日期。行之间用分隔线。
- **主页**：顶部一行“继续阅读”横向卡片，每张 300×120：左边是封面，右边是书名、作者和“图书 · 18%”。卡片底色取封面的平均色，加 20% 白色叠加和渐变【采】。下方是“最近添加”封面网格。
- **空书库**：居中显示 Books 图标（64px，`--c-label-3`），下面是标题“把繁体书拖到这里”（15/600）、说明“支持 epub、mobi、azw3、fb2、txt”，以及一个“添加图书”按钮。
- **拖入文件时**：整个内容区出现 2px 虚线圆角框，`--c-accent`，背景 6% 不透明的强调色。
- **生成封面**（没有封面的书）：2:3 的色块，颜色由书名哈希从 6 种柔和色里选。书名用 22px 宋体粗体排在上三分之一，作者用 13px 排在底部。

## 2. 阅读窗口（参照 `mac-tahoe26-reading-window-two-page-light-zh-callouts.png`）

### 2.1 布局
- 整个窗口背景是主题背景色，没有任何边框或分隔线。
- 单页/双页：内容宽度 ≥ 1000px 时双页，否则单页【定，苹果阈值未公开】。
- 双页：左右外边距 = 窗宽 × 6.4%【采】，中缝 = 窗宽 × 6.9%【采】。单页：版心最大宽度 680px，水平居中。
- 上边距 72px（工具栏让位），下边距 52px（页脚）。【采：正文从窗口顶部约 10% 处开始】
- “页边空白”滑块调的是左右外边距的倍数：0.5×–1.8×，默认 1×。

### 2.2 工具栏（自动隐藏）
- 高 52px 的透明条，内容垂直居中。
  - 左：玻璃胶囊，内含 3 个按钮：目录、书签列表、要点精选。按钮 36×36，胶囊左右内边距 4px。
  - 中：书名，用 `--t-headline`、`--c-label-2`，单行省略。
  - 右：玻璃胶囊，内含“繁/简”、“大小”（外观）、搜索；接着是一个独立的玻璃圆形书签按钮（36px）；最后是 Windows 窗口按钮。
- 何时出现：指针进入顶部 64px、按 Alt 键、打开任何面板时，工具栏都会显示。指针离开 1.2 秒后自动隐藏（有面板开着时不隐藏）。【官：指针移到顶部才显示】
- **繁/简按钮**是本产品独有的。它是一个文字按钮，显示的是**当前状态**：简体模式下显示“简”，原文模式下显示“繁”。悬停提示“显示原文（Ctrl+J）”或“显示简体（Ctrl+J）”。书本身就是简体的，这个按钮置灰。
- “大小”按钮：用文字“大小”而不是图标【采】，“大”字 15px、“小”字 11px，两字底部对齐。

### 2.3 Windows 窗口按钮
- 每个按钮 46×32，贴在窗口右上角。图标用 Segoe Fluent Icons 字形：最小化 E921、最大化 E922、还原 E923、关闭 E8BB，字号 10px。
- 悬停背景：rgba(0,0,0,.06)，深色模式 rgba(255,255,255,.08)。关闭按钮悬停：#C42B1C 背景，白色图标。
- 书库窗口里常驻；阅读窗口里随工具栏一起显示和隐藏。

### 2.4 翻页与页脚
- 指针移到左右边缘 80px 以内时，出现玻璃圆形箭头按钮（40px），淡入 150ms，点击翻页。【官】
- 翻页方式：点击页面左右三分之一区域，← → ↑ ↓、PageUp、PageDown、滚轮、触控板左右轻扫。
- 页脚（常驻，`--t-callout`，颜色是主题文字色的 45% 不透明）：
  - 中间：`161 / 418`（当前位置 / 总位置数，用 foliate 的 location）。
  - 右边：`本章还剩 2 页`。
  - 左边：跳转后才出现。28px 圆形按钮，里面写着跳转前的页码，点击回到原处。【官】

### 2.5 “主题与设置”弹出面板（参照 `mac-tahoe26-reading-appearance-panel-quiet-dark-en.png`）
- 从“大小”按钮下方弹出，宽 300px，玻璃材质，圆角 16px，内边距 16px，带一个指向按钮的小三角。
- 从上到下：
  1. 标题“主题与设置”，`--t-title3`，居中。
  2. 一行控件：
     - 左边是字号分段按钮 `[ 小A | 大A ]`，高 32px，两个按钮之间有 1px 分隔线。
     - 右边是页面模式的三个圆形按钮：浅色、深色、自动（太阳、月亮、半圆图标）。
  3. 主题方块，2 行 × 3 列，每个 84×64，间距 8px。
     - 方块的底色是主题背景色，中间是用该主题字体写的“Aa”（20px），名称写在方块里的底部（11px）。
     - 选中的方块有 2px 描边，浅色模式用 #000，深色模式用 #FFF。
  4. 全宽按钮“⚙ 自定义”，高 36px，圆角 10px。
- 点“自定义”后，面板在原位展开成第二页（左上角有“‹ 返回”）：
  - 字体：一行，右边显示当前字体名和 ›，点进去是字体页（见下）。
  - 西文字体：同样一行，默认“跟随中文字体”，点进去是同一个字体页（推荐组最前面多一项“跟随中文字体”，没有“原始”）。
  - 字号：滑块，12–48px，步长 1，右上角显示当前值；不受下面“自定义”开关管。第一页的“小A/大A”仍按 2.7 的档位跳，滑块调出的值不在档位上时，从最接近的档位继续跳。
  - 粗体文本：开关。
  - 开关“自定义”（关闭时下面的滑块都是灰的）：行间距、字符间距、词间距、页边空白（滑块）；两端对齐（开关）。
  - 底部是红色文字按钮“还原主题”。
- **字体页**（从“字体”或“西文字体”点进去；宽度同面板，高度 560px 或窗口高减 100px，取小的；左上“‹ 返回”，标题“字体”或“西文字体”）【定】：
  1. 搜索框，高 32px，圆角 10px：按中文名或英文名过滤，不分大小写。
  2. 列表，三组依次是：**推荐**（原始、宋体、微软雅黑、楷体、等线，即 0.1 的 5 项）、**我导入的**、**系统字体**；空组不显示。
     - 系统字体里，有汉字（“简”U+7B80）的在前，其余按名称排序；没有汉字的右侧标灰色小字“无中文”，仍可选。推荐里已有的家族不再在系统字体里重复。
     - 每项高 48px：第一行是名字（15px，用它自己的字体），第二行是示例“繁体简读 Aa”（12px，`--c-label-2`，同一个字体）；原始一项的第二行写“用书里指定的字体”。
     - 选中项名字用强调色，右侧打勾。我导入的每项悬停时，右侧出现删除按钮（代替勾）。
     - 列表虚拟滚动，只渲染看得见的行；打开时把选中项滚进视野。
  3. 底部全宽按钮“导入字体…”（高 36px，同“自定义”按钮）：弹出文件选择框，支持 .ttf .otf .ttc .woff .woff2。
  4. 选中后正文立即生效，阅读位置不跳。
  5. 选的字体被卸载或删掉后自动退回宋体，字体页和自定义页顶部显示一条提示“字体 X 不可用，已改用宋体”（可关闭，关掉面板即算看过）。
- 西文搭配：西文默认跟随中文字体；宋体、楷体、仿宋、明体一类西文字形难看的，“跟随”时前面自动加 Georgia（沿用 0.1 的规则）。

### 2.9 目录、书签、搜索弹出面板
- 都从对应按钮下方弹出，宽 320–360px，最大高度 70vh，内容可滚动。
- **目录**：多级缩进，每级 16px，当前章节加粗并在左侧显示一个蓝点。
- **书签**：每条显示章节名、片段和日期。悬停时显示删除按钮。
- **搜索**：
  - 顶部是搜索框（自动获得焦点；输入繁体或简体都可以，内部都转成当前显示的字形）。
  - 结果按章节分组，每条是一段片段，匹配词加粗。点击跳转，并在页面上闪烁高亮该处 1.2 秒。
