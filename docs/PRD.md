# 繁体简读 · 产品说明

> 本文说明产品要做什么、不做什么。实现与本文冲突时，以本文为准。

## 1. 一句话

一个安静、好看的电子书阅读器。打开繁体中文书时，**默认直接显示成排版正常的简体书**。

## 2. 要解决的问题

- 简体中文读者读繁体书，要么忍受字形和用语的差异，要么借助各种转换工具，步骤繁琐。
- 很多繁体 epub 是**从 PDF 转出来的**：汉字之间夹着换行留下的空格，段落在原 PDF 分页处被截断。
- 现有阅读器都不能一步把它变成“正常排版的简体书”。

## 3. 平台

- Windows 10/11（x64）、macOS 13+（Apple 芯片与 Intel）。
- 无后端，不联网，所有数据存在本机。

## 4. 核心能力

### 4.1 繁转简（纯代码，离线，基于 OpenCC）
1. 字形：幣 → 币。
2. 词汇：台湾、香港用语 → 大陆用语（軟體 → 软件、網路 → 网络、影片 → 视频）。可以单独关掉。
3. 标点：「」 → “”，『』 → ‘’；竖排专用标点 → 普通标点。
4. 书名、作者、目录、图片替代文字同样转换。
5. **默认自动**：打开繁体书直接显示简体。是不是繁体书，按书的语言标记加用字统计自动判断。
6. 阅读工具栏上有一个“繁/简”按钮，一键切回原文，再点一下切回简体。按书记住。
7. **原文件永远不改**，转换只在显示时进行。

### 4.2 排版清理（从 PDF 转来的书）
- 只在检测到书是从 PDF 转出来的时才启用。正常排版的 epub 一个字都不动。
- 删掉汉字和汉字之间的多余空格。汉字与英文、数字之间的空格保留。
- 合并在分页处被截断的段落。规则保守：**宁可漏修，不可误伤**。
- 汉字之间的换行（不论哪种书）一律去掉。这个规则风险很低。

### 4.3 竖排书
- 竖排书默认改成横排显示（翻页方向随之改为从左往右）。设置里可以改回竖排。

## 5. 功能清单

| 区域 | 功能 |
|---|---|
| 导入 | 拖拽到窗口、文件选择、在文件管理器里双击文件打开（文件关联） |
| 格式 | epub、mobi、azw3、fb2、txt（txt 自动识别 UTF-8、UTF-16、GB18030、Big5 编码，并自动分章） |
| 书库 | 封面墙和列表两种视图；排序：最近阅读、书名、作者、添加时间；主页“继续阅读”；没有封面的书自动生成封面；从书库移除 |
| 阅读 | 每本书在独立窗口打开；自动保存阅读位置；单页或双页随窗口宽度自动切换；点击左右边缘、方向键、PageUp/PageDown、滚轮翻页；章节跳转快捷键 |
| 导航 | 目录；书内搜索（搜简体也能搜到）；书签；跳转后左下角出现“返回”按钮；页脚显示页码、本章剩余页数 |
| 外观 | “主题与设置”弹出面板：字号增减（另有 12–48px 精细滑块）；**字体可随意选择：系统已安装的任意字体，或导入自己的字体文件**；浅色、深色、自动；6 个主题（原始、安静、纸张、粗体、平静、专注）；“字体与版式”页一直可调：字体、粗体、栏数（自动/单栏/双栏）、行间距、页边距、字符间距、词间距、两端对齐；恢复默认 |
| 标注 | 高亮（黄、绿、蓝、粉、紫）、下划线、笔记；“要点精选”列表，点击跳转；编辑、删除 |
| 繁简 | 自动转换、繁/简按钮、设置里三层开关（字形始终开，词汇、标点可关）、排版清理开关、竖排转横排开关 |
| 其他 | 深色模式；界面参考 macOS 图书的风格；Windows 版窗口按钮用 Windows 样式 |

## 6. 以后的版本

- 自定义藏书、已读完；连续滚动模式；进度滑块；查词典；导出标注（Markdown）；阅读目标；编辑书籍信息；PDF 重排阅读。
- 跨设备同步；AI 翻译外语书；生词本；朗读；移动端。
- **不做**：书店、有声书、购买，以及一切与购买相关的功能。

## 7. 已定的设计决策

| 决策 | 结论 | 理由 |
|---|---|---|
| 桌面外壳 | **Electron（官方原版二进制，不改动）+ 解压即用的文件夹/zip**；首次运行自动建快捷方式与文件关联。仓库里的 Tauri 代码保留，不作为交付 | 不需要安装程序，不需要代码签名；官方二进制原样使用，不含任何原生模块 |
| 字体 | 界面字体用系统自带字体；阅读字体可任选系统字体或导入 | 安装包小，不打包受限字体 |
| 图标 | Phosphor（MIT 协议） | 风格接近系统图标，且可以随软件分发 |
| 窗口按钮 | Windows 版用 Windows 样式；macOS 版用系统红黄绿 | 符合各平台习惯 |

## 8. 验收标准

1. 打开一本繁体 epub，3 秒内显示成简体，汉字间没有多余空格，被分页截断的句子已经接上。
2. 点“繁/简”按钮，1 秒内切换，阅读位置不丢。
3. 关掉再打开，回到原来的位置。高亮、笔记、书签都还在。
4. 6 个主题、深色模式、字号、字体全部生效，切换时阅读位置不跳。
5. 书库导入 epub、mobi、azw3、fb2、txt 各一本，都能打开并转成简体。
6. 自动化测试全部通过。
